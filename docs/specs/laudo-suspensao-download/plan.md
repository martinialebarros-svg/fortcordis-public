# Plano

1. Adicionar a coluna com padrão habilitado para os downloads existentes. Persistir a suspensão com auditoria, preservando a revisão clínica.
2. Aplicar o estado no portal, na entrega de arquivos, no link direto e no aviso externo. Reusar a atualização existente do PDF publicado.
3. Expor o controle no detalhe interno, o status na lista e a mensagem de suspensão nas telas de parceiros.
4. Exercitar suspensão, edição e retomada em ambiente local. Homologar em Stage antes da promoção pelo fluxo do repositório.

Para interromper a entrega de uma versão com falha sem reabrir downloads, preservar o bloqueio no servidor até regularizar o acesso. Uma reversão para o código anterior ignora a coluna e reabre o download de laudos suspensos. A migração é aditiva e a coluna pode permanecer durante a reversão.
