# Plano

1. Reutilizar a interface de revisão e abrir a central com os dois códigos vindos da lista ou o código da ficha individual.
2. Exibir a mesma interface em diálogo de revisão no Atendimento, sem alterar o formulário clínico.
3. Validar a seleção, a inversão, a divergência de tutor e o adiamento com dados fictícios. Não é necessária migração. Para reverter, remover os atalhos e restaurar a interface da central, preservando as revisões já guardadas.
